# Expense-Tracker
A simple web-based Expense Tracker built with HTML, CSS, and JavaScript to track income and expenses.

## Features
- Add and delete transactions
- Automatically calculates total balance, income, and expenses
- Clean, responsive user interface

## Files
- `Expense tracker.html` – Main structure of the app
- `style.css` – Styling and layout
- `script.js` – Expense calculation and interactive logic
